You are given Python code that builds a quantum circuit with Qiskit. Without running the code,
produce the circuit's directed acyclic graph (DAG).

Rules
- One node per operation actually applied to `qc`, after unrolling loops, function calls and if/else.
- A node line is: <id> <gate>[(<params>)] <wires...>
  wires are q<i> for qubits (in argument order) and c<i> for classical bits.
  Write angles as decimals rounded to 3 places (pi/4 -> 0.785).
- An edge A -> B exists when B is the NEXT operation after A on some wire. List every wire it carries.
  If two consecutive operations share several wires, that is ONE edge listing all of them.
- Ids are integers starting at 0 and must respect the edges (an edge always goes from smaller to larger id).
- Output only the graph, in exactly the format shown below.

Example 1
Code:
```python
qc = QuantumCircuit(2)
qc.tdg(0)
qc.sdg(1)
qc.crz(-pi / 2, 0, 1)
qc.cx(0, 1)
qc.rx(-pi / 2, 0)
```
Graph:

CLBITS 0
NODES

1 sdg q1
2 crz(-1.571) q0 q1
3 cx q0 q1
4 rx(-1.571) q0
EDGES
0 -> 2 : q0
1 -> 2 : q1
2 -> 3 : q0 q1
3 -> 4 : q0
